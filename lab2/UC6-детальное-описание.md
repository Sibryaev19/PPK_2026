# UC6. Выполнить доставку (включает доставить заказ)

Детальное описание варианта использования по системе «Модель системы 2026.drawio».

## Таблица 1 — Детальное описание варианта использования UC6

| UC6 | Поле | Содержимое |
|---|---|---|
| | **Название** | Выполнить доставку (включает доставить заказ) |
| | **Описание** | Реализуется цикл доставки: курьер создаёт маршрут, следует ему и доставляет неотменённые заказы клиенту (включаемый UC2 «Доставить заказ») |
| | **Основная задача** | Выполнение доставки заказов клиенту по маршруту |
| | **Цель** | Обеспечить получение клиентом неотменённых заказов доставки |
| | **Актёры** | 1. Курьер (Инициатор)<br>2. Клиент (Участник) |
| | **Предусловия** | Собранные заказы переданы курьеру |
| | **Постусловия** | Все неотменённые заказы доставки получены клиентом |
| | **Основной поток** | 1. Курьер создаёт маршрут доставки<br>2. Курьер следует маршруту<br>3. Курьер доставляет неотменённые заказы (включаемый UC2) |
| | **Альтернативы** | 2.1. Маршрут непроходим (пробка, закрытая дорога) — курьер создаёт новый маршрут и следует ему (возврат к событию 2)<br>2.2. Клиент отменил все заказы доставки — курьер возвращается на предприятие, доставка завершается |
| | **Исключения** | 1. Создать маршрут невозможно (адрес недоступен, связность дорог отсутствует) — доставка не начинается, заказы возвращаются на предприятие<br>3. Заказ не доставлен (сработало исключение UC2) — заказ возвращается на предприятие, доставка завершается |

## Таблица 2 — Обоснование принятых решений (не для отчёта)

| Решение | Обоснование |
|---|---|
| Инициатор — Курьер | Единственный актёр, действующий во всех событиях потока; после получения заказов (предусловие) именно курьер начинает доставку по своей воле |
| Клиент — Участник без собственных событий | Получает доставку (связь «Получает» в PDOM), но его действия — вручение и проверка — находятся внутри включаемого UC2; дублировать их в UC6 нельзя (устранение многократного описания) |
| Оператор и Предприятие — не актёры UC6 | Их работа завершается до старта UC6: назначение курьера — UC9, сборка заказов — UC3/UC8. По методичке показываются только актёры, связанные с данным прецедентом |
| Доставка, Заказ, Маршрут — не актёры | Это объекты предметной области (сущности PDOM), а не внешние сущности, управляющие взаимодействием |
| Предусловие «собранные заказы переданы курьеру» | UC8 «Забрать заказ (курьер)» существует отдельно и не включается в UC6, поэтому его результат — предусловие UC6 |
| Событие 1 «Курьер создаёт маршрут» | По PDOM маршрут создаёт именно курьер (связь Курьер—Маршрут «Создает», 1–1). Событие даёт точку отсчёта для исключения 1 |
| Событие 2 «Курьер следует маршруту» | Глагола движения в PDOM нет; замена на «выполняет доставку» конфликтовала бы с названием самого UC6 |
| Событие 3 «доставляет неотменённые заказы» | Точка включения UC2 (зафиксирована в названии UC6, включаемый вариант выполняется всегда). Слово «неотменённые» уточняет область действия: заказ мог быть отменён по пути (UC10 существует отдельно) |
| Событие 4 «отмечает выполнение» отсутствует | Постусловие становится истинным уже после события 3; лишний шаг ничего не добавлял и делал бессмысленным гипотетическое исключение на нём |
| Цель не совпадает с постусловием | Цель — устремление («чего достигаем»), постусловие — проверяемый критерий корректного достижения цели |
| Альтернатива 2.1 (новый маршрут) | Отклонение с возвратом в русло — альтернатива по методичке. Именно перестроения маршрута порождают связь «многие-ко-многим» Маршрут—Доставка из PDOM |
| Альтернатива 2.2 (отмена всех заказов) | Отмена — легитимный сценарий системы (UC10 «Изменить заказ (включая отменить)»), а не авария; альтернативный поток, ведущий к собственному завершению UC, допустим по лекции Л02 |
| Исключение 1 (невозможно создать маршрут) | Без маршрута реализация UC6 невозможна — завершение UC исключено, что соответствует определению исключения в методичке |
| Исключение 3 (срыв включаемого UC2) | По семантике include включаемый вариант выполняется всегда, поэтому базовый UC обязан обработать его срыв. Выбрано завершение доставки (строгая трактовка методички: исключение делает успешное завершение невозможным) |
| Глаголы «создаёт», «доставляет», «получает» | Терминологическая согласованность описания с глаголами связей PDOM («Создает», «Доставляет», «Получает») |
