| UC4 | Поле | Содержимое |
|---|---|---|
| | **Название** | Оплатить счет |
| | **Описание** | Клиент выбирает счет и проводит оплату, в результате деньги списываются, а в счет добавляется информация о транзакции. |
| | **Основная задача** | Провести оплату по счету. |
| | **Цель** | Закрыть клиенту свои обязательства по счету. |
| | **Актёры** | 1. Клиент <br>2. Счет |
| | **Предусловия** | Клиент авторизован, сущность "Счет" создана. |
| | **Постусловия** | Деньги списаны, в счет добавлена транзакция. |
| | **Основной поток** | 1. Клиент выбирает счет (ID, Сумма) из списка доступных для оплаты.<br>2. Клиент выполняет команду "Оплатить" и подтверждает выбор метода оплаты.<br>3. Запрашивается подтверждение транзакции у платежной системы.<br>4. Получено подтверждение об успешном списании средств.<br>5. В счет добавляется новая транзакция. |
| | **Альтернативы** | 3.1. Недостаточно средств на балансе - платежная система возвращает отказ. Клиент может изменить способ оплаты (возврат к событию 2) или отменить действие.<br>3.2. Ошибка связи с платежной системой (тайм-аут) - ответ не получен, клиенту предлагается повторить попытку позже. Транзакция не создается. |
| | **Исключения** | 2. Клиент нажимает кнопку "Отмена" в диалоговом окне подтверждения оплаты - сценарий прерывается, счет остается неизменным.<br>4. Ошибка валидации данных - при подтверждении обнаруживается, что срок действия счета истек или сумма изменилась. Клиенту выводится ошибка. |
