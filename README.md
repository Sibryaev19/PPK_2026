# PPK_2026 — групповой проект

Курс «Проектирование программных комплексов». Описание проекта — реализация кодом не предусмотрена.

## Паспорт

| Поле | Значение |
|---|---|
| Название ПС | Медицинская система поддержки принятия врачебных решений **«МедЭксперт»** (СППР) |
| Предметная область | амбулаторный приём: сбор данных обследования, предварительная диагностика, подготовка плана лечения |
| Идея и каркас | [docs/00-концепция-и-каркас.md](docs/00-концепция-и-каркас.md) — **главный документ, начинать отсюда** |
| Обзор простыми словами | [docs/как-работает-система.md](docs/как-работает-система.md) — что и как работает + цепочка A-0 → A1 → A2 → A3 |
| Актёр | Врач (роль одна, врачей много — каждый со своего АРМ) |
| Архитектура | клиент-сервер: много АРМ врачей → единый сервер обработки (модули-одиночки) |
| Внешние сущности | Внешняя МИС · Аптечный сервис (две) |
| Хранилище | D1 — локальная БД обследований (единственный накопитель, доступен только серверу) |

## Согласованность (проверять перед сдачей)

- Номера функций IDEF0 = номера процессов DFD = охват прецедентами (таблица трассировки §6 концепции).
- Классы PDOM = основа диаграммы классов ЛР6; словарь данных актуален.
- Единственный накопитель — D1; Внешняя МИС и аптечный сервис — внешние сущности, не накопители.
- Клиент-сервер: АРМВрача (0..*) — каждый серверный модуль (1); все интеграции и D1 — только через сервер.
- Система предлагает, врач решает: формулировки «предварительный диагноз», «проект плана лечения» — везде одинаковые.
